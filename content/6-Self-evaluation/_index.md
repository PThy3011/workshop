I participated in the **First Cloud Journey** program and completed various hands-on labs using core AWS services, including **IAM, VPC, EC2, S3, Route 53, Transit Gateway, Storage Gateway, Security Hub, Lambda, and AWS Backup**. Throughout the internship, I gained practical experience in designing hybrid cloud infrastructures, performing virtual machine migration, and implementing cloud cost optimization and security best practices.

These activities helped me strengthen my skills in **cloud administration, networking, security and compliance, Infrastructure as Code (AWS CloudFormation), serverless computing, troubleshooting, technical blog/worklog writing, and teamwork**.
